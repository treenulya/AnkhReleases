# Ankh — обновления

Здесь лежат только готовые установщики Ankh и файл `latest.json`, по которому установленные
копии приложения находят новую версию и обновляются сами. Кода приложения здесь нет.

Файлы обновляет команда `npm run release` в проекте Ankh. Установщики подписаны: приложение
ставит обновление, только если подпись совпадает с его встроенным ключом.
